Ephraims Webserver Automation Project

This page was installed and published without any manual steps. The project automates the setup of an Nginx web server on Ubuntu (WSL): the configuration is defined as code, the server is configured to match it, and the result is verified automatically.

Tools used

Terraform Defines the settings as code and generates config.json, the single source of truth.
Ansible Installs Nginx, keeps the service running, creates a dedicated user and deploys this page.
Python Runs the chain in order and verifies that the server and page work as expected.

The chain

Terraform → Ansible → Python
